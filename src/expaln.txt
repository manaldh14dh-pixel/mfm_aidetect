src/ (or scripts/): Contains Python scripts and modules for various
stages of the data science pipeline.
o data_preparation.py: Functions for data cleaning,
preprocessing, and feature engineering.
o modeling.py: Classes and functions for building, training, and
evaluating machine learning models.
o visualization.py: Functions for generating plots and
visualizations.
o utils.py: Helper functions and common utilities used across
different modules.
models/: Stores trained machine learning models
(e.g., .pkl, .joblib files).
