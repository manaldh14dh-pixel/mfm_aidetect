# mfm Aidetect
# Detection of AI-Generated Arabic Text: A Data Mining Approach

## Project Overview
This project is part of the MSIS822 course. 
The goal is to detect whether Arabic research abstracts are written by humans or generated by AI using data mining techniques.


## Dataset
- **Name:** arabic-generated-abstracts 
- **Source:** [Hugging Face](https://huggingface.co/datasets/KFUPM-JRCAI/arabic-generated-abstracts) 
- **Content:** Arabic abstracts labeled as *human-written* or *AI-generated*.
